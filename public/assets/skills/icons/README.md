# Skill icons

Place PNG icons here for skills (24×24 or 32×32 recommended). Filename = skill id + `.png`.

**Current skills:**
- `continuous_laser.png` – continuous laser / heat vision
- `immunity_5s.png` – 5-second immunity (shield)
- `movement_speed_5s.png` – movement speed boost for 5 seconds
- `healing_5s.svg` – 5-second strong health regeneration (healing)
- `fury_7s.svg` – 7-second Fury (increased size and damage)

**Free icon sources:**
- [OpenGameArt: Icons](https://opengameart.org/content/icon-pack)
- [Kenney: Game Icons](https://kenney.nl/assets/game-icons)
- [itch.io: Skill Icons](https://itch.io/game-assets/free/tag-icons)

If a file is missing, the game falls back to the built-in Kenney laser image for the continuous laser skill.
